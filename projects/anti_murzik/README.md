# Anti-Murzik ( Диванный страж )

> Мобильный робот на шасси радиоуправляемой машинки для защиты мебели от котов и прочих вредителей.

## Концепция

Робот "Anti-Murzik" — это автономная система защиты мебели, которая патрулирует контролируемую зону и отпугивает котов и других животных с помощью водяного "плевка". Робот оснащен камерой (опционально), датчиками расстояния и системой дистанционного управления по Wi-Fi.

## Аппаратная часть

### Мозг
- **ESP32** — микроконтроллер с Wi-Fi и Bluetooth

### Движение
- **Шасси** — на базе радиоуправляемой машинки (колёса, редукторы)
- **Моторы** — 2 коллекторных двигателя постоянного тока
- **Драйвер** — L298N или MX1508 для управления моторами

### Система полива
- **Насос** — водяная помпа от ирригатора (5-12V)
- **Трубка** — силиконовая трубка для подачи воды
- **Резервуар** — пластиковая бутылка 0.33-0.5 л с герметизацией штуцера
- **Управление** — MOSFET-транзистор (IRLZ44N) или реле, управляемое ESP32

### Питание
- **Аккумуляторы** — 2-3 шт. 18650 Li-ion
- **Понижающий DC-DC** — модуль на основе LM2596 для питания ESP32 (3.3V/5V)
- **Защита** — предохранитель, выключатель питания

## Программная часть

### Платформа
- **Framework** — Arduino (ESP32)
- **IDE** — PlatformIO (VS Code)
- **Язык** — C++17

### Функционал
1. **Дистанционное управление** через веб-интерфейс:
   - Кнопки движения (вперед/назад/влево/вправо)
   - Кнопка активации водяного насоса
   - Статус датчиков и уровня воды

2. **Автономные функции**:
   - Патрулирование по заданному маршруту
   - Датчик расстояния (HC-SR04) для предотвращения столкновений
   - Датчик движения (PIR) для обнаружения животных
   - Автоматическая активация насоса при обнаружении движения

3. **Веб-сервер**:
   - REST API для управления
   - WebSocket для实时 обновлений
   - Адаптивный веб-интерфейс (работает на смартфоне)

4. **Неблокирующая архитектура**:
   - Все таймеры на `millis()`
   - Никаких `delay()` в основном цикле
   - конечные автоматы (State Machine) для управления состоянием робота
