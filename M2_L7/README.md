# Lesson 07 - Pointers, Arrays and Strings

## What this lesson covers

- Arrays: many values under one name, counting from zero
- Addresses and pointers: `&` gives an address, `*` reaches through it
- Where things live: globals, statics, locals, text in quotes
- Passing an array to a function, and why its length travels with it
- Strings as `char` arrays, and building text with `snprintf`
- Printing a number in decimal, octal and hexadecimal
- Reading a button, and why one press can count as five
